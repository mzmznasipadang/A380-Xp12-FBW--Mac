# A380 for X-Plane 12 1.0.6.1

1.0.6 with the macOS cockpit screens and three FlyByWire updates. The flight
model is unchanged from 1.0.5: the .acf and airfoils are still built from your
own X-Plane 12's Airbus A330-300.

## What's new since 1.0.5

- **macOS:** the cockpit screens run in X-Plane's own browser, and typing works
  in the MFD and EFB. The plugin loads on macOS 27.
- **Flight controls (FlyByWire #10940):** the A380X flight control laws, flight
  envelope, flight guidance and THR LK.
- **Wingtip brakes and APPU (FlyByWire #10933).**
- **EFIS control panel NAVAID buttons (FlyByWire #10914).**
- **OANS:** reads the current airport map database and shows its icons.

## Install

This release is an update. It holds the plugin (`win.xpl`, `mac.xpl`) and the
cockpit screens, not the 3D model, textures or sounds.

1. **Install 1.0.5 first**, if the aircraft isn't installed yet:
   - **Windows 10 or later:** run the installer from the
     [1.0.5 release](https://github.com/Vihaan2012-cmyk/A380-For-X-Plane-12-Based-on-The-FBW-A380/releases),
     pick your X-Plane folder and a texture size (1K to 8K).
   - **Mac and Linux:** run `bash mac.sh` (or `bash linux.sh`) from
     `tools/beta/` in this repository. It builds the aircraft from source and
     installs it, and it builds this version already, so skip step 2.
2. **Close X-Plane**, download `A380-1.0.6.1-update.zip` below and unzip it.
3. **Copy** the `A380 for X-Plane 12` folder from the zip over
   `X-Plane 12/Aircraft/A380 for X-Plane 12` and let it replace the files.
4. **Mac only**, once, in Terminal:

   ```
   xattr -dr com.apple.quarantine "X-Plane 12/Aircraft/A380 for X-Plane 12"
   ```

You need X-Plane 12 with Laminar's Airbus A330-300 installed, as for 1.0.5.

## Known

- The Windows plugin in this update hasn't been flown on Windows yet. If it
  doesn't load, put back the `win.xpl` from 1.0.5 (rerun its installer) and
  open an issue with your `Log.txt`.
- `XPHFBW.exe` and `fbw_a380_systems_server.exe` stay at 1.0.5. They're only
  used with the browser screens turned off.

## Bugs

Open an issue with your X-Plane `Log.txt`. It records the aircraft's state at
every start.
